📄 Have only a PDF? (like NACHT) — how to convert

A PDF is a picture of the score with no note data, so it can't be played directly. Convert it once — free — then load the result here:

  1. Open MuseScore 4 (free, musescore.org) → File → Import PDF → pick your PDF.
  2. Check the notes, then File → Export → MusicXML (.mxl).
  3. Drop that .mxl file above. Done.

Many pieces (incl. Kohlstedt's) are also on musescore.com as ready-made MusicXML/MIDI downloads.
